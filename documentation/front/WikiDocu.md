# Wiki

Esta guía conserva el nombre por compatibilidad con enlaces históricos. El frontend actual no monta una página Wiki: [`App.tsx`](../../frontend/src/App.tsx) no registra `/wiki` ni `/wiki/:section`. Aunque [`routes.ts`](../../frontend/src/shared/config/routes.ts) conserva una constante Wiki, una constante no equivale a una ruta activa. No hay aquí una descripción de una función disponible.
